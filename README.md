# Accessible Profile Portfolio

Verbesserungsmöglichkeiten:

Oben:
- Unter kleiner Info Text: Soll die Kontaktdaten in der Mitte sein.

Mitte:
- kurzer Info Text Über Mich soll hinzugefügt werden.
- Sprachkenntnisse bei Gebärdensprache das Gebärdenzeichen.
- Bewerbungsunterlagen sollen in dem jeweilligen Bereich als Icon hinzugefügt und als Fenstergeöffnet werden und Zeugnisse getrennt

Unten:
- Standort soll die Map aufklappbares Fenster sein und erst beim Klick geöffnet werden.
- Kontaktdaten stehen zwei Felder kopieren, einer reicht.
- Untere Leiste: soll Kontaktdaten: soll Kontakt kopieren, teilen hinzugefügt werden.
